# Taller QGIS: del dato al mapa

Programa formativo para convertir planillas y otras fuentes en evidencia geoespacial clara, verificable y útil para la toma de decisiones.

## Qué se aprende

El taller recorre un flujo práctico de cuatro sesiones:

1. **Fundamentos y calidad del dato:** entorno QGIS, formatos vectoriales, sistemas de referencia y carga de capas.
2. **Tablas y cruces:** limpieza de datos, uniones espaciales, integración de planillas y validación de tipos.
3. **Análisis:** consultas, campos calculados, filtros y selección de zonas de interés.
4. **Comunicación:** simbología, composición cartográfica y exportación para impresión o medios digitales.

## A quién está dirigido

Personas que comienzan a trabajar con SIG o que necesitan ordenar y comunicar datos territoriales. Se recomienda tener QGIS instalado, un mouse y conexión estable para una modalidad en línea.
